# koreanseris

2026 KBO 한국시리즈 **KT 위즈 vs 삼성 라이온즈** 예측 시뮬레이터입니다. 하나의 HTML 페이지로 동작합니다.

> 11월 3일 1차전 직전까지 공개된 정보로 만든 **모델 예측**입니다. 실제 경기 결과가 아닙니다.

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 서버나 설치는 필요 없습니다.

## 페이지 구성

- **시리즈 전망**: 우승 확률, 4승 0패~4승 3패 경우의 수, 시리즈가 몇 차전에서 끝나는지
- **차전별 예상**: 1~7차전 선발 매치업, 승리 확률, 예상 점수
- **경기 시뮬레이터**: 차전 번호(1~7)를 넣으면 1회~9회(연장 포함) 타석별 결과, 투수 교체 시점과 이유, 불펜·마무리 운용 시나리오, 투수 등판 확률, 타자 예상 활약
- **근거**: 정규시즌·포스트시즌 사실관계, 감독·전문가 시각, 출처

## 모델 개요

- 타석 단위 몬테카를로 시뮬레이션: 차전별 800경기, 시리즈 40,000회
- 반영 요소: 좌우 플래툰, 구장(대구 홈런 보정), 투수 휴식일·투구수·연투, 1차전 KT 실전 공백, 삼성 PO 직후 불펜 피로, 6차전 이후·탈락 위기의 총력전 운용
- 기본 선발 로테이션
  - KT: 대니엘 → 고영표 → 로건 → 소형준
  - 삼성: 최원태 → 페덱 → 후라도 (원태인은 불펜·마무리)
- 시리즈는 최대 7차전이며, 무승부 없이 승부가 날 때까지 연장전을 치르는 것으로 가정합니다.

## 한계

- 선수 능력치는 보도된 시즌 성적을 바탕으로 한 추정치입니다.
- 라인업은 고정이며 대타·대주자·부상은 반영하지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 완성된 페이지 (엔진 포함) |
| `src/engine.js` | 선수 데이터와 시뮬레이션 엔진 |
| `src/template.html` | 화면 구성과 스타일 |
| `build.py` | `src` 파일을 합쳐 `index.html`을 다시 만듭니다: `python3 build.py` |
